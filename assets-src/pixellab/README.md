# PixelLab characters made for this game

Downloaded from PixelLab (standard mode, 64 px, 8 directions, low top-down, "mannequin" template:
the same settings as the pack's wizard and mentor). The importer reads these folders like the pack's
`characters/`. Each folder keeps PixelLab's own `metadata.json` (prompt, size, date).
