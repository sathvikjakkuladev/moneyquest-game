# v1 art kept from the old build

Smooth Meta AI art from the first MoneyQuest build (its `public/assets/` output), kept because the
asset importer turns these into pixel art for things the MoneyQuest Assets pack doesn't have: pets,
the Bull Calf walk cycle, the Laurel Wreath icon, the world map, and the stand-in Stormwatch and
Crossroads mentors. The original `MakeBank Assets` pack and the old build were deleted, so this is
the only copy: treat it as read-only input.
