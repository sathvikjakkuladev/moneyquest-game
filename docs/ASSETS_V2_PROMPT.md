# Move MoneyQuest onto the new assets_v2 art

This prompt has two parts, because part of the work needs my Mac and part of it doesn't.

- **Part A runs locally**, in VS Code from the `game` folder. It needs `../assets_v2`, `../MoneyQuest Assets/` and `../make-bank-question-bank.csv`, which only exist on my Mac. It covers the decisions and Phase 1, and it leaves the repo set up so the cloud never needs those folders again.
- **Part B runs in Claude Code cloud sessions**, one session per phase (Phases 2–5). A cloud session clones the GitHub repo and nothing else. It keeps working while my laptop is closed.

If you're reading this in a cloud session, skip to Part B.

The new art set replaces the old pixel art with the bold vector cartoon look I approved ("Style A", like Prodigy Math). It is about 1.5 GB and 4,223 files, of which about 30 MB ships.

## Ground rules (both parts)

- **`../assets_v2` is a read-only input**, like the CSV. Add it to the hard rules in CLAUDE.md. Never edit, move or commit it. The importer reads it and writes the shipped files.
- **Generated output stays generated.** `public/assets/**`, `src/assets/manifest.json`, `ASSET_REPORT.md` and anything else the importer writes are re-made by re-running it, never hand-edited.
- **Ship only what the game uses.** Skip anything with `runtime: false`, plus `_set-aside/`, `source/`, `_tools/`, `_review/` and the green-screen masters.
- **Convert images to WebP at the sizes the game draws, and re-encode the WebM clips at about 384 px tall.** The budgets still hold: first load under 10 MB, whole game under 40 MB, 60 fps on a mid-range Chromebook at 4× CPU throttle.
- **The rest of CLAUDE.md stays as it is:**
  - Kids' privacy rules.
  - Reward cards: the reward code files are untouched, and no printed codes go in the repo.
  - Save versioning: bump `SAVE_VERSION`, add a migration and a test.
  - Accessibility: text 18 px or more, contrast, keyboard play, read-aloud.
  - The phase workflow: typecheck clean, tests passing, one commit per phase, a PLAN.md log entry and a `docs/AI_USE.md` update.
- **Mark drafts.** AI-written learning text or labels are drafts. That includes the hat rarities and the colour-set names in assets_v2.
- **Production stays safe.** `main` deploys to play.nhsqa.org, so none of this work merges into `main` until I say so. All of it goes on an `assets-v2` branch (see below).

## Step 1: ask me these decisions before coding

Ask them together with clear options and your recommendation, then record my answers in PLAN.md as a "Decisions (assets_v2)" section. **The cloud sessions only know what's in the repo, so every answer, rule and detail they'll need goes into PLAN.md, not just into our chat.**

1. **Rendering.** The game is pixel art throughout: 640×360, Phaser `pixelArt: true`, nearest-neighbour scaling. The new art is smooth vector, so propose the new internal resolution, scaling and filtering. Also say what replaces the Rendering section of CLAUDE.md.
2. **World and topics.** The game has 10 zones: 6 topics plus 4 bonus zones. The new art has Ledgerhold (the hub) and 7 districts, each with 2 monster species and a boss, plus the Debt Dragon finale.
   - Propose how the question bank's 6 topics map onto the 7 districts. Employment and Income has no obvious district.
   - Say what happens to the 4 bonus zones, which have no new art.
   - Say how Money Check 1 and 2 and the bonus-portal rules carry over.
3. **Monster data.** Monster data must come only from `src/data/monster_attacks.json`. It's generated by `tools/import-assets.ts` and uses the old monster names keyed by the old zones. Propose how to regenerate it for the new species and bosses, keeping the effect rules, without hand-editing it. Prefer a way the cloud can re-run: any input it needs (a names and attacks table, say) lives in the repo, not in `../`.
4. **Pets.** In the new design, pets and monsters are the same: beating a monster captures it, and I pick one captured monster as my pet. The current game has shop pets and taming in the bonus zones. Propose the new rules. Keep pets at +2 damage, or +4 for legendary.
5. **Bull Calf and the Laurel Wreath.** CLAUDE.md requires the Bull Calf pet and the Laurel Wreath hat to exist, be visible and never be buyable.
   - assets_v2 has no Bull Calf. Propose one, such as a reward-only look of the `hype-bull` monster or the old v1 sprite.
   - The new laurel hat folder is `laurel-wreath`, but the game id must stay `hat-laurel`, so map it rather than renaming the id.
6. **Customization.** "Hats and pets only" becomes:
   - body choices: skin, eyes, 7 hairstyles in 12 colours, 6 faces;
   - 25 hats with Prodigy-style hair rules;
   - 8 costume colour sets.

   Propose how the colour sets are earned or bought, how old saves map their hats and pets to the new ones, and the new save shape.
7. **Multiplayer.** Other players need to see your look. Propose how look choices travel in `src/net/protocol.ts`: as list indexes, validated on both sides, append-only. Explain how that fits the privacy rules.
8. **Old art.** Say what happens to the old pixel pipeline (`../MoneyQuest Assets/`, `assets-src/`, PixelLab, the old room layouts and the `fronts` system) once nothing uses it.

Don't write game code until I've answered.
